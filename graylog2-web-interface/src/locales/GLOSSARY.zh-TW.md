# Traditional Chinese (Taiwan) glossary

Terms used in the Traditional Chinese (Taiwan) translations (`zh-TW/*.json`), so the whole interface uses the same words.

## Style

- Use Traditional Chinese characters (zh-TW) with Taiwan vocabulary and software terminology (NOT mainland terms): 伺服器 (not 服务器), 資料 (not 数据), 檔案 (not 文件), 使用者 (not 用户), 儲存 (not 保存), 設定, 預設, 軟體, 網路, 資訊, 搜尋, 登入/登出, 匯入/匯出, 訊息, 程式. Polite neutral tone; omit the pronoun where the English addresses the user, use 您 only where needed. Use full-width punctuation (，。：；？！（）) in Chinese sentences, but keep ASCII punctuation inside code, placeholders, URLs and numbers. Corner quotes 「」 may be used for quoted names. No space between Chinese characters. Keyboard names: "Ctrl", "Shift".
- Keep product and feature names in English: Graylog, Enterprise, Data Lake, Security, Stream, Dashboard, Widget, Input, Output, Extractor, Pipeline, Sidecar, Content Pack, Index Set, Lookup Table, Collector, Fleet, Event Definition, Forwarder, Illuminate, Sigma, Watchlist, MITRE ATT&CK, Investigation, Asset, Detection Chain, Data Tiering, Input Profile, Content Hub, OpenSearch.
- Translate only the value. Keep every `{{placeholder}}`, `<tag>` / `</tag>` and `<0>`-style Trans markers exactly as they are, plus technical identifiers in `backticks`.
- `<empty>`-style values that look like tags may stay English (the helper treats them as tags).
