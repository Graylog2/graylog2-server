# Simplified Chinese glossary

Terms used in the Simplified Chinese translations (`zh-CN/*.json`), so the whole interface uses the same words.

## Style

- Use Simplified Chinese (zh-CN) as used in mainland China software UIs, polite neutral tone without "您" overuse (use "您" only where the English addresses the user directly, otherwise omit the pronoun). Use full-width punctuation (，。：；？！（）) in Chinese sentences, but keep ASCII punctuation inside code, placeholders, URLs and numbers. Put no space between Chinese characters; keep a single space between Chinese text and Latin words/numbers only where natural. For ongoing actions use "…" or "..." as in the English text. Keyboard names: "Ctrl", "Shift".
- Keep product and feature names in English: Graylog, Enterprise, Data Lake, Security, Stream, Dashboard, Widget, Input, Output, Extractor, Pipeline, Sidecar, Content Pack, Index Set, Lookup Table, Collector, Fleet, Event Definition, Forwarder, Illuminate, Sigma, Watchlist, MITRE ATT&CK, Investigation, Asset, Detection Chain, Data Tiering, Input Profile, Content Hub.
- Translate only the value. Keep every `{{placeholder}}`, `<tag>` / `</tag>` and `<0>`-style Trans markers exactly as they are, plus technical identifiers in `backticks`.
- Plural keys: for `_one` use the singular form with the number, for `_many`/`_other` the plural form (Chinese has only `_other`).

- Terminology follows the dominant usage of the catalog: English for Stream, Dashboard, Pipeline, Sidecar, Collector, Fleet, Forwarder, Lookup Table, Extractor, Collection, Event Definition, Investigation; Chinese for 组件 (Widget), 索引集 (Index Set), 内容包 (Content Pack), 节点 (Node), 告警 (Alert), 事件, 通知, 报告, 资产, 令牌, 集群. Keep a space between English terms and Chinese text.
