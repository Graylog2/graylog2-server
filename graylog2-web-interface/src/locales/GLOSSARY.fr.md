# French glossary

Terms used in the French translations (`fr/*.json`), so the whole interface uses the same words.

## Style

- Address users formally with "vous"; use infinitive or imperative (vous) for buttons ("Créer", "Supprimer"). Use French typography where natural (non-breaking space before ":" is NOT required, keep plain spaces). Use "..." for ongoing actions like the English texts. Keyboard names: "Ctrl", "Maj" for Shift.
- Keep product and feature names in English: Graylog, Enterprise, Data Lake, Security, Stream, Widget, Input, Output, Extractor, Pipeline, Sidecar, Content Pack, Index Set, Lookup Table, Collector, Fleet, Event Definition, Forwarder, Illuminate, Sigma, Watchlist, MITRE ATT&CK, Investigation, Asset, Detection Chain, Data Tiering, Input Profile, Content Hub.
- Translate only the value. Keep every `{{placeholder}}`, `<tag>` / `</tag>` and `<0>`-style Trans markers exactly as they are, plus technical identifiers in `backticks`.
- Plural keys: for `_one` use the singular form with the number, for `_many`/`_other` the plural form (Chinese has only `_other`).
