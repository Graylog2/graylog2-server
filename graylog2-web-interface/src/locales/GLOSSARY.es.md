# Spanish glossary

Terms used in the Spanish translations (`es/*.json`), so the whole interface uses the same words.

## Style

- Address users with the informal "tú" form consistently (tu/tus, "has", imperatives like "Crea"); buttons and menu items use the infinitive ("Crear", "Eliminar"). Use neutral international Spanish (no regional slang). Use "..." for ongoing actions like the English texts. Keyboard names: "Ctrl", "Mayús" for Shift.
- Keep product and feature names in English: Graylog, Enterprise, Data Lake, Security, Stream, Dashboard, Widget, Input, Output, Extractor, Pipeline, Sidecar, Content Pack, Index Set, Lookup Table, Collector, Fleet, Event Definition, Forwarder, Illuminate, Sigma, Watchlist, MITRE ATT&CK, Detection Chain, Data Tiering, Input Profile, Content Hub.
- Translate only the value. Keep every `{{placeholder}}`, `<tag>` / `</tag>` and `<0>`-style Trans markers exactly as they are, plus technical identifiers in `backticks`.
- Plural keys: for `_one` use the singular form with the number, for `_many`/`_other` the plural form (Chinese has only `_other`).
