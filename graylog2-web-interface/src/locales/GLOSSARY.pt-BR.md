# Brazilian Portuguese glossary

Terms used in the Brazilian Portuguese translations (`pt-BR/*.json`), so the whole interface uses the same words.

## Style

- Use Brazilian Portuguese (pt-BR spelling and vocabulary, not European). Address users with the neutral "você" form or impersonal/infinitive forms for actions; avoid "tu". Use "..." for ongoing actions like the English texts. Keyboard names: "Ctrl", "Shift".
- Keep product and feature names in English: Graylog, Enterprise, Data Lake, Security, Stream, Dashboard, Widget, Input, Output, Extractor, Pipeline, Sidecar, Content Pack, Index Set, Lookup Table, Collector, Fleet, Event Definition, Forwarder, Illuminate, Sigma, Watchlist, MITRE ATT&CK, Investigation, Asset, Detection Chain, Data Tiering, Input Profile, Content Hub.
- Translate only the value. Keep every `{{placeholder}}`, `<tag>` / `</tag>` and `<0>`-style Trans markers exactly as they are, plus technical identifiers in `backticks`.
- Plural keys: for `_one` use the singular form with the number, for `_many`/`_other` the plural form (Chinese has only `_other`).
