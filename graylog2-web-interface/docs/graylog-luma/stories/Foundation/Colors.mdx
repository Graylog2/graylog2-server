# Colors

## Overview

The Graylog app handles large amounts of data, and our color system aids users in understanding information, tracking actions, finding help, and identifying next steps. Consistently using our product's Luma color palette reduces cognitive load and fosters a cohesive and engaging user experience. The chosen colors are clear, accessible for all users, and allow the data to be the primary focus.
