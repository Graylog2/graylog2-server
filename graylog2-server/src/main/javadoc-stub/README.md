# Graylog Server Javadoc

This JAR is a placeholder to satisfy the Maven Central requirements. We don't publish generated Javadoc HTML for
`graylog2-server` to reduce the publishing size.

The Javadoc comments are available in the `graylog2-server-<version>-sources.jar` artifact. IDEs like IntelliJ IDEA
and Eclipse show them automatically when the sources are downloaded.

- Source code: https://github.com/Graylog2/graylog2-server
- Documentation: https://go2docs.graylog.org/
